# Rasul Desktop

Rasul is a personal AI agent that runs on your Windows PC. You control it from Rasul Desktop or from the [Rasul Android app](https://github.com/rasul-app/rasul).

Status: early development. The code is published here at the first release; nothing is ready to install yet.

رسول: وكيل ذكاء اصطناعي شخصي يعمل على حاسوبك بنظام Windows، وتتحكم به من تطبيق Rasul Desktop أو من تطبيق Rasul على Android. المشروع في بدايته، ولا يوجد إصدار للتثبيت بعد.
